# Estudos de Git e GitHub


## O que é Git? 
Git é um sistema de controle de versão que permite acompanhar e gerenciar as alterações de um projeto.
 
 
 ## O que é branch? 
Branch é uma ramificação do projeto usada para desenvolver ou testar mudanças separadamente.

## O que é Tag?  
É uma marcação usada para identificar uma versão ou ponto imortante do projeto.

## O que é origin?
Origin é o nome dado pelo Git ao reósitorio remoto  principal, geralmente o reposiório no GitHub. x  

## O que é Remote?
É a conexão do meu repositório local com um repositório remoto.

## Para que serve Clone? Como se usa?
Serve para copiar um repositório remoto para meu computador. Uso `git clone`.

## Para que serve Pull? Como se usa?
Serve para baixar e atualizar as alterações do repositório remoto. Uso `git pull`.

## Para que serve Commit? Como se usa?
Serve para salvar as alterações no histórico do projeto. Uso `git commit`.

## Para que serve Push? Como se usa?
Serve para enviar minhas alterações para o repositório remoto. Uso `git push`.?

## Outros nomes de remotes
Além de origin, podemos utilizar nomes como upstream e backup.
Esses nomes identificam outros repositórios remotos configurados no Git.

## O que é Merge?
Merge é a operação utilizada para integrar as alterações de uma branch em outra.
Uso: git merge develop.

## O que é Pull Request?
Pull Request (PR) é uma solicitação para revisar e integrar alterações de uma branch em outra.
É utilizado no GitHub para permitir análise e aprovação antes do merge.

## O que é Origin?
Origin é o nome convencional atribuído ao repositório remoto principal.
É um apelido que identifica esse repositório na configuração do Git.

## O que é Remote?
Remote é uma referência configurada no Git para um repositório remoto.
Permite conectar o repositório local a outros repositórios hospedados, como no GitHub.
