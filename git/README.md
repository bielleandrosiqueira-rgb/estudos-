Estudos de Git e GitHub

O que é Git?
Git é um sistema de controle de versão que permite acompanhar e gerenciar as alterações de um projeto.

O que é branch?
Branch é uma ramificação do projeto usada para desenvolver ou testar mudanças separadamente.

O que é Tag?
É uma marcação usada para identificar uma versão ou ponto importante do projeto.

O que é origin?
Origin é o nome dado pelo Git ao repositório remoto principal, geralmente o repositório no GitHub.

O que é Remote?
É a conexão do meu projeto com um repositório na internet. pode ser no Git Hub, Git Lab o Bitbuncket.

Para que serve Clone? Como se usa?
Serve para trazer um projeto do GitHub pro meu computador. Uso 'git clone'.

Para que serve Pull? Como se usa?
Serve para pegar as atualizações do GitHub. Uso 'git pull'.

Para que serve Commit? Como se usa?
Serve para salvar o que fiz no projeto. Uso 'git commit'.

Para que serve Push? Como se usa?
Serve para mandar minhas alterações pro GitHub. Uso 'git push'.

Outros nomes de remotes
Também existem nomes como upstream e backup para identificar outros repositórios 

O que é Merge?
É juntar as alterações de uma branch com outra.

O que é Pull Request?
É pedir para alguém revisar minhas alterações antes de juntar uma branch com outra.
